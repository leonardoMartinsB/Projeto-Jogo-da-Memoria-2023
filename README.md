## 🚀 Sobre o Projeto

Este é o **meu primeiro projeto de jogo**, desenvolvido em 2023 com a orientação do professor **Roilwane Borges (Manual do Dev)**.
O objetivo foi criar um **Jogo da Memória** temático inspirado em **Rick and Morty**, onde o jogador precisa encontrar os pares corretos de cartas no menor tempo possível.

> Além de divertido, o projeto foi uma ótima forma de praticar **HTML, CSS e JavaScript** na prática.

---

## 🎮 Como Jogar

1. Acesse o jogo clicando [aqui](https://leonardomartinsb.github.io/Projeto-Jogo-da-Memoria-2023/).
2. Digite seu nome na tela inicial.
3. Clique em **Iniciar Jogo**.
4. Encontre os pares de cartas iguais para vencer.

---

## 🖥️ Tecnologias Utilizadas

* **HTML5** → estrutura da aplicação
* **CSS3** → estilização e design temático
* **JavaScript (Vanilla)** → lógica do jogo (embaralhar cartas, checar pares, pontuação)
